4. Scenarios from the command line
- Run them with foodrec scenario run scenarios/*.json. Each run starts from an empty temporary database and never touches your real data.
- There are about 20 step types (onboard, recommend, feedback, chat, resolve, repeat, set role, expect checks, and more). Recipes can be picked by rank, title, or "the best/worst recipe in the list on a criterion", which helps simulate consistent behaviour.
- To compare models, add --matrix llm.model=modelA,modelB, or use --set key=value to change any setting.
- Each run writes report.json, export.json and summary.md. The command fails if any check fails, so it can run in CI.
- Example scenarios are role-based study, and amodel comparison).
