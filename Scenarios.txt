Things the dry run turned up, so they don't surprise you on stage

- Place questions in chat don't filter. "What did I reject at work?" returns all rejects. The graph stores place, but the chat parser has no place slot, so ask by time and type only.
- The cool-down step is always titled "Topic recently dismissed", even when the user answered the question. Call it a cool-down.
- Compare answers are hard to read when you name recipes. The values are printed in the order you named the recipes, not winner first. For example, "Hummus and Veggie Plate is higher (0.67 vs 1.0)" came back when Greek Salad was named first. Asking by rank ("Compare #1 and #2") keeps it readable.
- The "What changed" banner leaves out profile changes. After a profile change it lists the recipes that entered and left, but no changed input, because compare() only diffs weights, filters and versions (foodrec/service.py:201). Say out loud that the allergy rule caused the change.
- Oat Porridge (a breakfast) shows up in dinner lists. The meal/place context is recorded with feedback but is not used as a filter.
